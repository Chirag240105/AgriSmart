# Merge ML Features and Payment Integration

## Overview
This PR merges all ML features with the payment-integrated site into a single working application.

## Features Added
- ✅ **Disease Detection**: AI-powered plant disease identification using MobileNetV2 (85-95% accuracy)
- ✅ **Price Prediction**: Ensemble model for crop price forecasting (99% accuracy)
- ✅ **Weather Integration**: Real-time weather data for farming decisions
- ✅ **AI Chatbot**: Intelligent farming assistant
- ✅ **Payment Integration**: Preserved from payment-integrated_Site branch

## Technical Changes

### ML Server (New)
- Flask server on port 5001
- Disease detection model: `plant_disease_model.h5` (9 MB)
- Price prediction models in `models/` folder
- Complete API endpoints for all ML features

### Backend Integration
- New routes: `/api/disease`, `/api/prices`, `/api/weather`
- New controllers: diseaseController, priceController, weatherController
- New services: diseaseDetectionService, priceStreamService, weatherService
- Added AI SDK dependencies for chatbot

### Frontend Integration
- Updated pages: DiseasePage, PricesPage, WeatherPage
- All ML endpoints connected via API service
- Responsive UI for all new features

## Setup Instructions

### ML Server
```bash
cd ml-server
pip install -r requirements.txt
python app.py
```

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd agrismart-frontend
npm install
npm run dev
```

## Environment Variables Required
- ML Server: PORT=5001
- Backend: ML_SERVER_URL, WEATHER_API_KEY, AI API keys
- Frontend: VITE_API_URL=http://localhost:1212
