## About

**AgriSmart** is an innovative platform that brings modern technology to agriculture. Whether you're managing crop health, monitoring soil conditions, or optimizing irrigation, AgriSmart provides intelligent solutions to enhance productivity and sustainability in farming.

The project combines frontend and backend technologies to deliver a seamless experience for agricultural management and decision-making.

## Features

- 🌱 **Crop Management**: Track and manage crops throughout their lifecycle
- 📊 **Data Analytics**: Visualize agricultural metrics and performance insights
- 💧 **Smart Irrigation**: Optimize water usage with intelligent recommendations
- 🌡️ **Weather Integration**: Real-time weather data for better planning
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 🔔 **Alerts & Notifications**: Get timely alerts for critical farm events
- 📈 **Yield Prediction**: AI-powered insights to forecast crop yields

### Frontend
